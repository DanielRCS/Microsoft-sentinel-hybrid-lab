# Investigation 006 - Atomic Red Team Multi-Stage Activity

## Incident Summary

A multi-stage security simulation was performed on the COFFEE Windows 10 endpoint using Atomic Red Team.

The activity included system discovery, domain account discovery, network discovery, registry-based persistence, scheduled task creation, and suspicious PowerShell execution.

The goal of the investigation was to identify the full activity chain in Microsoft Sentinel, map the behavior to MITRE ATT&CK techniques, and determine what actions were successful, blocked, or left behind on the endpoint.

---

## Incident Details

- Host: `COFFEE`
- User: `KINGDOM\it.admin`
- Start Time: August 26, 2026 at approximately 1:30:44 PM
- Data Sources:
  - Windows Security Events
  - Sysmon
  - Microsoft Sentinel
  - Microsoft Defender
- Simulation Tool: Atomic Red Team

---

## Initial Activity

The investigation began by reviewing authentication activity for the account performing the actions.

Relevant events included:

- Event ID 4624 - Successful Logon
- Event ID 4672 - Special Privileges Assigned

Event ID 4672 showed that the account received special privileges during logon, but no evidence was found showing that the user performed a separate privilege escalation during the simulation.

---

## Discovery Activity

Several discovery commands were executed from the COFFEE endpoint.

Observed commands included:

```text
hostname
whoami
systeminfo
ipconfig /all
netsh interface show interface
arp -a
nbtstat -n
net config

```

This activity was used to gather information about the local system and network configuration.

### Information Collected

The activity provided visibility into:

- Current user
- Computer hostname
- Operating system information
- Local IP configuration
- Network interfaces
- ARP cache
- NetBIOS information
- Local network configuration

## Domain Account Discovery

Domain information was enumerated using built-in Windows commands.

Observed command:

```text
cmd.exe /c net user /domain & net group /domain
```

This allowed enumeration of:

- Domain user accounts
- Domain groups

Microsoft Sentinel captured the related process creation events, including:

- `cmd.exe`
- `net.exe`
- `net1.exe`

After process command-line auditing was enabled, the full command arguments were visible in Event ID 4688.

## Registry Persistence

Atomic Red Team generated registry-based persistence using a Windows Run key.

The modified location was:

```text
HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
```

A value named:

```text
Atomic Red Team
```

was created.

The configured data referenced an executable path intended to simulate automatic execution during user logon.

An additional Atomic Red Team test registry key was also observed under:

```text
HKCU\Software\Classes\AtomicRedTeam
```

The test used registry modifications to simulate persistence behavior.

---

## Scheduled Task Persistence

A scheduled task named:

```text
spawn
```

was successfully created.

The task was configured as a one-time scheduled task.

Its action used:

```text
C:\Windows\System32\cmd.exe
```

to create a marker file used by Atomic Red Team.

The marker file contained test text indicating the action was generated by the Atomic Red Team simulation.

This confirmed that scheduled task creation was successful.

Successful execution through the scheduled task was not confirmed in Sentinel.

---

## PowerShell Activity

Suspicious PowerShell activity was also generated during the simulation.

The test included:

- Encoded PowerShell commands
- Base64 content
- Registry interaction
- Creation of a test marker file
- Additional script execution

The PowerShell test attempted to write an `art-marker.txt` file and interact with the `AtomicRedTeam` registry key.

---

## Microsoft Defender Interaction

The PowerShell Atomic test was interrupted by Microsoft Defender / AMSI security controls.

The test returned an access-denied condition and did not complete successfully.

The exact Microsoft Defender detection name was not identified in Sentinel.

Because of this, the finding was documented as:

> Microsoft Defender interrupted the PowerShell Atomic test. The exact Defender detection name was not available in Sentinel.

This was treated as successful defensive prevention rather than a failed investigation.

---

## Persistence Execution Status

Persistence mechanisms were successfully created, including:

- Registry Run key
- Scheduled task

However, successful execution through those persistence mechanisms was not confirmed in Microsoft Sentinel.

The investigation therefore concluded:

> Persistence artifacts were created, but successful execution through the persistence mechanisms was not confirmed.

---

## Privilege Escalation Review

Event ID 4672 was observed for the user account.

This event indicates that special privileges were assigned during logon.

No additional evidence was identified showing that the account gained new administrative or Domain Admin privileges during the Atomic Red Team simulation.

**Finding:** No evidence of privilege escalation identified.

---

## Findings

The investigation confirmed that:

- A domain user successfully accessed the COFFEE endpoint.
- Multiple system and network discovery commands were executed.
- Domain users and groups were enumerated.
- Process creation and command-line telemetry were captured in Sentinel.
- Registry-based persistence was created.
- A scheduled task named `spawn` was created.
- Suspicious PowerShell activity was attempted.
- Microsoft Defender interrupted the PowerShell test.
- No evidence of successful privilege escalation was identified.
- Persistence execution was not confirmed.
- Multiple Atomic Red Team artifacts remained on the endpoint after testing.

---

## Remediation

Cleanup was performed after the investigation was completed.

The following artifacts were removed:

- Scheduled task `spawn`
- `Atomic Red Team` Run key value
- Atomic Red Team registry artifacts
- `art-marker.txt` test file

Verification confirmed:

- The `spawn` task no longer existed.
- The Atomic Red Team Run key value was removed.
- The additional `AtomicRedTeam` registry key was no longer present.
- `art-marker.txt` was no longer present.
- The remaining Run key contained only the legitimate OneDrive startup entry.

---

## Final Classification

**Severity:** High

**Classification:** True Positive - Authorized Security Simulation / Atomic Red Team Exercise

The activity matched multiple behaviors that would be considered suspicious in a production environment, including domain discovery, network discovery, scheduled task creation, registry persistence, and encoded PowerShell execution.

The activity was intentionally generated as part of an authorized lab simulation.

---

## Final Conclusion

This investigation demonstrated a full multi-stage security workflow using Microsoft Sentinel.

The investigation covered:

- Authentication review
- Process analysis
- Command-line analysis
- Domain discovery
- Network discovery
- Registry persistence
- Scheduled task persistence
- PowerShell execution
- Defender prevention
- MITRE ATT&CK mapping
- Remediation and cleanup

This was the first investigation in the lab that combined multiple techniques into a single attack-style timeline instead of analyzing one isolated event.
